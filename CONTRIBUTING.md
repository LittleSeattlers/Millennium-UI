# Contributing

Contributions to the public dashboard, accessibility, documentation, tests, and data-contract hardening are welcome.

Before opening a pull request:

1. Run `pnpm validate`.
2. Keep the site fully static and GitHub Pages compatible.
3. Do not add raw attempts, event logs, research prose, contributor data, local paths, commands, credentials, model telemetry, or quota data.
4. Do not add a workflow or dependency that can read the private Millennium repository.
5. Treat new public data fields as a privacy and schema change requiring explicit review.

Research submissions are not accepted through this UI repository.
